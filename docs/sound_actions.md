# Tibia client: sound bank / "action" map

Source: `packages/Tibia/sounds/sounds-ce31d979....dat` (protobuf `tibia.protobuf.sound.Sounds`),
decoded with the `sounds.proto` / `sounds-common.proto` FileDescriptorProto blobs embedded in `bin/client.exe`
(offsets 0x01bc9020 and 0x01bc50c0).

- 844 `.ogg` files in `sounds/`, all 844 are referenced by the bank (0 orphans, 0 missing).
- 592 `NumericSoundEffect`, 91 `AmbienceStream`, 9 `AmbienceObjectStream`, 25 `MusicTemplate`.
- 325 of the 336 `ESoundEffectType` enum values resolve to a `NumericSoundEffect`;
  267 further effect entries (ids 2645+) have no enum name; they are ambience / UI / item / event sounds
  addressed by raw id only.

## Trigger chain

```
server -> GAMESERVER_MESSAGE_TYPE_SOUNDTRIGGER
   SOUND_TRIGGER_TYPE_NUMERIC_SOUND   -> NumericSoundEffect.id  (== ESoundEffectType value)
   SOUND_TRIGGER_TYPE_AMBIENCE_STREAM -> AmbienceStream.id
   SOUND_TRIGGER_TYPE_MUSIC_TEMPLATE  -> MusicTemplate.id

NumericSoundEffect
   .numeric_sound_type  -> ENumericSoundType   = the mixer category / "action"
   .simple_sound_effect.sound_id   OR   .random_sound_effect.random_sound_id[]
   .random_pitch / .random_volume  (MinMaxFloat)

Sound.id -> Sound.filename = "sound-<sha256>.ogg"
(Sound.original_filename exists in the schema but is empty in this build.)
```

Notes:

- `NUMERIC_SOUND_TYPE_CREATURE_ATTACK` (7) has **zero** entries in this bank. Monster melee
  effects (`SOUND_EFFECT_TYPE_MonsterMeleeAttack*` 100-107, `MonsterCloseAttackFist` 2) are
  tagged `NUMERIC_SOUND_TYPE_WEAPON_ATTACK` (4), same as player weapon swings. So the
  "Creatures > Attacks" checkbox cannot be keyed off numeric_sound_type alone, because the client
  must decide by the source creature of the trigger.
- 11 `ESoundEffectType` values have no `NumericSoundEffect` and are therefore silent in this
  build: `Silence` (0), `SpellOrRune` (10), `Other` (11), `SpellSummonMonkFamiliar` (1198),
  `MonsterSpellAgony` (2069), `MammalMammothBark` (2531), `HumanSageBark` (2542),
  `HumanCroneBark` (2543), `ApeBark` (2544), `MammalMammothDeath` (2631),
  `GodspellKillAllMonsters` (10001).

## Specific answers

### "echo raid" / raid announcement

- action: `NUMERIC_SOUND_TYPE_RAID_ANNOUNCEMENT` (value 17)
- `NumericSoundEffect` id **2776**, `SimpleSoundEffect` -> Sound id **677**
- file: `sounds/sound-736ee6347dfa7d9842f634c3ab7396a3b0dcd20c62a920e8a51728689b515801.ogg` (1.29 s)
- UI label "Raid Announcements", option key `/options/RaidMessagesEnabled`, volume `soundUiVolume`
- it is the only sound in the whole bank with this type.

### monsters

- idle barks: `NUMERIC_SOUND_TYPE_CREATURE_NOISE` (5) - enum `SOUND_EFFECT_TYPE_*Bark`, ids 2500-2544
  (+ unnamed ids 2645, 2715, 2717, ... for newer creature classes)
- deaths: `NUMERIC_SOUND_TYPE_CREATURE_DEATH` (6) - enum `SOUND_EFFECT_TYPE_*Death`, ids 2600-2644
- melee hits: `SOUND_EFFECT_TYPE_MonsterMeleeAttack{Fist,Claw,Bite,Rip,Acid,Magic,Ethereal,Construct}`
  ids 100-107, plus `MonsterCloseAttackFist` = 2
- monster spells: `SOUND_EFFECT_TYPE_MonsterSpell*` ids 2002-2069
  (SingleTarget / SmallArea / LargeArea / Wave x Fire,Energy,Earth,Ice,Death,Holy,Hit,LifeDrain,
  ManaDrain,Drowning,Bleeding,Healing, plus Challenge/Speed/Summon/Teleport/Fear/Root/Agony/...)
  routed through SPELL_ATTACK / SPELL_HEALING / SPELL_SUPPORT.

### environment / ambience

- `NUMERIC_SOUND_TYPE_AMBIENCE_STREAM` (8): 125 one-shot ambience effects, ids 2651-2912, all unnamed.
- `AmbienceStream` (91 entries): one long looping `.ogg` (`is_stream = true`) plus a list of
  `DelayedSoundEffect` (`numeric_sound_effect_id` + `delay_seconds`) layered on top.
  The server picks the stream id per area.
- `AmbienceObjectStream` (9 entries): loops driven by how many objects from
  `counted_appearance_types` are visible; each `AppearanceTypesCountSoundEffect` gives a
  `count` threshold -> `looping_sound_id`, with `max_sound_distance` for the distance fade.
- Engine tunables (built-in `:/conf/config.ini`, `[SOUND]` section):
  `ambienceStreamFadeDuration=1000`, `ambienceObjectStreamFadeDuration=500`,
  `distanceFadePerStep=10`, `distanceFadeBase=100`, `distanceModifierForZ=3`,
  `disableAmbienceStreams=false`, `disableAmbienceObjectSounds=false`,
  `ambienceStreamSingleSoundsDelayMultiplier`.
